# krita-plugin
in macOS, 
Copy the folder of the plugin to ~/Library/Application Support/krita/pykrita/
 ,include kotlin_bridge.desktop,kotlin_bridge folder,
restart krita ,in python plugin manager check new plugin,name is kotlin App Bridge,reatart krita agein.
open Data to 3D Pro.
Under the script in the Tools menu, click on "Launch Kotlin Bridge Program"。
Two software will connect, and if they cannot connect, clicking the to_krita button on Data to 3D Pro will also connect.
and once connected, this app can send images to krita.
The operation under Windows is similar, but the directory where the plugin is placed has changed.
